# Ankomeow

Хосуудад зориулсан өдөр тутмын хамтын төлөвлөгөөний React апп. Улаанбаатарын цагаар (`Asia/Ulaanbaatar`) ажиллаж, өдөр солигдох бүрд өдрийн үзүүлэлтүүд шинэчлэгддэг.

## Дэлгэцүүд

| Дэлгэц | Тайлбар |
| --- | --- |
| Нүүр | Өдрийн товч байдал, цаг, хос сонголт |
| Ус | Уусан усны хэмжээ, жингээс хамаарсан зорилго, аяга дүрслэл |
| Жагсаалт | Хийх зүйлсийн жагсаалт |
| Дэлгэц | Дэлгэцний цагийн таймер |
| GIF | Зурган фрэймүүдээс GIF үүсгэх |

## Технологи

- React (hooks)
- [lucide-react](https://lucide.dev/) — дүрсүүд
- Inline style дээр суурилсан өнгөний систем (`C` объект), нэмэлт CSS санг ашиглаагүй

## Ашиглах

`tovlorokh-khamtrakh.jsx` нь нэг файлт компонент бөгөөд `export default function App()` буцаадаг. React төсөл дотроо импортлон дуудаж ашиглана:

```jsx
import App from "./tovlorokh-khamtrakh.jsx";
```

Шаардлагатай зависимс:

```bash
npm install react lucide-react
```
